# Changelog

## 1.1.0

- Added the `firmary-portal` plugin ("Firmary for Clients") for clients of a firm: the client portal MCP connector (`https://portal.firmary.app/api/mcp`) and a client skill, in `plugins/firmary-portal`.
- Added a Claude Code marketplace (`.claude-plugin/marketplace.json`) listing both plugins.
- The staff `firmary` plugin is unchanged apart from its version.
- The client skill covers answering "I don't have this" on a document request, message attachments in the upload card, booking from open times, and searching portal help.

## 1.0.0

- Initial release: Firmary remote MCP connector and the Firmary skill.
